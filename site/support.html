Quick guide

  • SHIFT (orange) uses the function printed in orange above a key; ALPHA (teal) types variables A–F, X, Y, M.
  • MODE switches between COMP, STAT, TABLE, EQN and BASE-N. SHIFT + MODE opens SETUP (Deg/Rad, Fix/Sci, exact results).
  • S⇔D toggles a result between exact form (fractions, √, π) and decimal.
  • To solve an equation: type it with ALPHA + CALC for “=”, e.g. X² = 2, then press SHIFT + CALC (SOLVE).
  • STO then a variable key stores the result; SHIFT + HIST shows stored values.
  • ▲ ▼ recall earlier calculations; HIST shows the full history.

Resetting the app

Open SHIFT + MODE → Reset all to clear variables, history and settings.
